# 境内の奇跡：全50種類の実装

## 今回の追加

既存の10種類と元の画像素材を維持し、未実装だった40種類を追加しました。50種類すべてに画像・描画・動きがあり、抽選・発見記録・図鑑・開発プレビューに対応します。

### 追加した40種類と動き

| カテゴリ | 今回の演出 |
| --- | --- |
| 動物（8） | 白猫の訪問と呼吸、三毛猫の歩行、キツネの振り返り、タヌキの顔出し、ウサギの小さな跳躍、鹿の静かな訪問、スズメの羽ばたきと飛行、ホタルの明滅 |
| 自然（8） | 二重虹、木漏れ日のゆらめき、雪の降下、初雪と枝、紅葉と枝の揺れ、落ち葉の旋回、朝露のきらめき、光の粒の浮遊 |
| 空（8） | 満月の光、三日月の浮上、天の川の漂い、オーロラの波、彗星の横断、星座の明滅、月の光輪、ハートの雲の移動 |
| 神秘（8） | 狐火、光る鳥居、揺れる鈴、光る絵馬、七色の風、光の足跡、光る御神木、金色の羽根の落下 |
| 神様（8） | 神聖な白狐、龍の横断と波打つ動き、鳳凰の飛来と翼、金色の蝶、黄金の境内、七色の流れ星、御神木の開花、空の光の鳥居 |

鳥居・鈴・木の演出では、元の境内SVGにも光・揺れ・色の変化を加えます。黄金の演出では背景を淡く温かな色にします。鈴の音は既存の音声設定に従い、ONかつブラウザが再生を許可している場合にのみ既存の優しい音を使用します。初期状態は無音です。

## 絵柄と軽さ

新しい40枚はリポジトリ専用に作った透明背景のSVGです。外部の画像・フォント・ライブラリは使っていません。桜色、生成り、薄紫、若草色、金色、穏やかな輪郭線を使い、境内のSVGに合わせています。元のPNG6枚は削除していません。

合計91,833バイト（約92KB、非圧縮）。各画像は別ファイルとしてビルドし、出現時と図鑑の発見済みサムネイルで必要に応じて読み込みます。旧画像を含めた全画像の先読みはしません。図鑑は遅延読み込みです。

動きはCSSのtransform・opacityを中心に、粒子は最大16個、同時演出は1種類です。`prefers-reduced-motion` では動かさずに表示します。「風をとめる」は粒子・背景の変化も含めてアニメーションを一時停止します。すべての装飾は操作を受け取らず、境内のボタンを操作できます。演出の×ボタンで終了することも可能です。

## 保存と抽選

保存キー、version、ID、初回発見日時、旧 `miracle` の解釈は変更しません。全50種類を既存の `encounters` に記録します。画像の読み込み失敗、画面移動、停止中には新たな発見を記録しません。同じ種類の再発見でも初回記録を保持します。

発生率とレアリティの設定は `src/encounters.ts` を変更せず使用します。基本のN/R/SR/SSR/UR割合は50/30/15/4/1%。感謝度・期待度による従来の傾向と、全体発生率の3倍設定を維持します。種類の追加に合わせ、同じレアリティ内で個別の重みを分配します。低い値でも50種類すべてに出会えます。

## 編集と拡張

- `src/miracleCatalog.ts`：名称、説明、レアリティ、実装状態、固定ID。
- `src/miracleVisuals.ts`：新しい40種類の配置・動き・粒子の対応。
- `src/VectorMiracle.tsx`：新しい演出の描画。
- `src/miracleAnimations.css`：各演出の動き、スマホ位置、停止・動きを減らす設定。
- `src/encounterImages.ts`：図鑑と境内で共有する画像URL。
- `src/assets/encounters/*.svg`：透明背景のオリジナル素材。
- `scripts/generate-miracle-art.py`：追加40枚の原稿。色・形を変える場合はこの原稿を編集し `python3 scripts/generate-miracle-art.py` で再生成します。実行時にPythonは不要です。

追加素材の著作権上の外部ライセンス依存はありません。今後別素材に差し替える場合は、その素材の利用条件を確認してください。

将来の季節・夜限定・隠し組み合わせは引き続き拡張用の構造です。この変更では新しい制限や特定時間へのログイン強制を設けません。

## 確認

全50種類の到達可能性と確率の正規化、画像URLの完全性、追加SVGの内容・容量、発見ログの保存・復元・重複防止を単体テストで確認します。ブラウザではスマホ・PCの両方で全50種類の表示と発見記録、既存機能、龍の移動、停止、動きを減らす設定、画像読み込み失敗を確認します。開発プレビューでも50種類を選択でき、手動再生でデータが増えないことを確認しました。

- Vitest 65件、Nodeの保存統合・バックエンドテスト13件成功。
- スマホ・PCのPlaywright 150件成功。全50種類×2構成の画像表示・記録、通常機能、動作停止と静止表示、SVG読み込み失敗時の保護を含みます。
- TypeScript型チェック・本番ビルド成功。全SVGのXML構文と、40種類のイラスト・動きの対応も確認。
- 開発プレビューで50種類を選択可能、手動再生は保存データを変更しません。動きの一時停止は実際のブラウザでも確認。
